# Pictures for the README

- `hero.svg`, `peek_<agent>.svg`: the animated henchmen, drawn by `peeks.py` from `call/android/avatars.py`.
- `panels/`: the feature cards, drawn by `panels.py` from the screenshots in `screens/` and the avatars.
- `screens/`: phone screenshots, tidied by `screens/polish.sh` (no status bar, rounded corners, a soft shadow).

The screenshots come from a staged demo crew, never from real conversations.
